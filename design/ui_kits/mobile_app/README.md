# Mobile App — UI Kit

Interactive recreation of the Nexus Moves iOS/Android customer app (dark, first).

`index.html` — the assistant chat screen with header progress card, message stream, suggestion actions, and composer. Tap **Share** to open the "Get ready to share" bottom sheet. Faithful to the shipped screens; components are inline cosmetic versions of the primitives in `/components` (ChatBubble, SuggestionButton, AssistantAvatar, ProgressBar, Banner, Sheet, ChecklistItem).
