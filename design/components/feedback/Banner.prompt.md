Inline callout. The `warning` tone (cream + amber) is Nexus's signature "honest nudge" — kind, never alarm-red — for surfacing gaps in the inventory.

```jsx
<Banner tone="warning">Only ~43 lbs logged for a 3-bedroom home, which usually totals around 8,000 lbs — worth a second pass before sharing.</Banner>
<Banner tone="success" icon={<CheckIcon />}>Every room has a walkthrough and the big items are photographed.</Banner>
```

Tones: `warning`, `success`, `info`, `danger`.
