A floating "verified item" chip — the product's signature proof-of-inventory moment. Object icon, name, weight/volume, and a green verified check. Use over hero illustrations and in captured-item lists.

```jsx
<ItemCard icon={<BoxIcon/>} name="Box" meta="44 lb" />
<ItemCard icon={<LampIcon/>} name="Lamp" meta="7 lb" />
<ItemCard icon={<ChairIcon/>} name="Chair" meta="15 lb" />
```

Icons follow the illustration/object style (blue-grey duotone or a Lucide line glyph). Weight/meta uses the mono font.
