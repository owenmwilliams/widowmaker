Icon-only button for compact controls (composer add/send, header ellipsis menu). Minimum 44px hit target on mobile.

```jsx
<IconButton tone="accent" aria-label="Send"><SendIcon /></IconButton>
```

Tones: `default` (neutral card), `accent` (solid blue send/primary), `quiet` (accent tint), `plain` (borderless). `round="circle"` (default) or `"square"`.
